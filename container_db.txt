Unplug a Pluggable Database (PDB) Manually

##########################################
 
Before attempting to unplug a PDB, you must make sure it is closed. 

To unplug the database use the ALTER PLUGGABLE DATABASE command with the UNPLUG INTO clause to specify the location of the XML metadata file.

Plugging in a PDB into the CDB is similar to creating a new PDB. First check the PBD is compatible with the CDB by calling the 

DBMS_PDB.CHECK_PLUG_COMPATIBILITY function, passing in the XML metadata file and the name of the PDB you want to create using it.
 
 
SQL> set serveroutput on
 
SQL> DECLARE

      l_result BOOLEAN;

    BEGIN

      l_result := DBMS_PDB.check_plug_compatibility(

                    pdb_descr_file => 'C:\app\azureuser\oradata\unplug_db\pdbsales.xml',

                    pdb_name       => 'pdbsales');

      IF l_result THEN

        DBMS_OUTPUT.PUT_LINE('compatible');

      ELSE

       DBMS_OUTPUT.PUT_LINE('incompatible');

     END IF;

   END;
