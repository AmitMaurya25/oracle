The high-level steps for RAC configuration prerequisites include:
#################################################################

1)Verify hardware and software requirements: Ensure that the hardware and software requirements for Oracle Grid Infrastructure and RAC database are met. This includes hardware components like CPU, memory, disk space, and network cards, as well as software components like operating system version, Oracle software versions, and patches.

2)Verify network requirements: Verify the network configuration and ensure that it meets the requirements for RAC. This includes setting up the private interconnect for RAC communication, configuring the public network, and ensuring that the network has adequate bandwidth and low latency.

3)Verify storage requirements: Ensure that the storage requirements for RAC are met. This includes setting up shared storage for the database files and configuring storage options like ASM (Automatic Storage Management) or cluster file system.

4)Configure user accounts and permissions: Create user accounts for the Oracle Grid Infrastructure and RAC database software, and configure the necessary permissions for those accounts.

5)Configure operating system prerequisites: Configure the operating system prerequisites for Oracle Grid Infrastructure and RAC database, including setting up kernel parameters, disabling unnecessary services, and configuring firewalls.

6)Verify DNS and hostname resolution: Verify that the DNS (Domain Name System) and hostname resolution are set up correctly, so that the nodes in the RAC cluster can communicate with each other.

7)Verify software prerequisites: Verify that the required software prerequisites for Oracle Grid Infrastructure and RAC database are installed on all nodes in the cluster, including packages like libaio, libstdc++, and libgcc.

fdisk /dev/sdb 

The sequence of answers is "n", "p", "1", "Return", "Return" and "w". 

Set ASM disks >>>> oracleasm configure -i
Initialization of oracleasm >>> oracleasm init 
Create ASM disks >>>> oracleasm createdisk ASM1 /dev/sdb1
Scan ASM disks >>>> oracleasm scandisks 
List ASM disks >>>> oracleasm listdisks

oracleasm createdisk ASM2 /dev/sdc1
